DE0 CPU Board

A 16-bit CPU written in Verilog, running on a virtual Terasic DE0. This is the real RTL compiled to WebAssembly, so every digit, LED and register below comes from the hardware model. Set the input on SW3–SW0, reset with SW9, and watch the program counter step through the program on the 7-segment display.
